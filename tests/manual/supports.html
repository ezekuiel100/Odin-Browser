Tudo verde = correto. Qualquer faixa VERMELHA e um bloco de @supports aplicado na hora errada.

1. condicao falsa nao aplica / not dela aplica

@supports not (nao-existe-mesmo: 1)

2. fallback nao sobrescreve o caminho moderno

@supports (display: grid) vence o @supports not (display: grid)

3. and / or

(display:grid) and (gap:1px)
(nao-existe:1) or (color:red)

4. custom property

@supports (--x: 1)

5. unidade nao suportada (50cqw): o fallback sobrevive (largura 320px)

width: 320px

6. selector()

selector(a:has(img)) sim, selector(::selection) nao

7. @supports aninhado (CSS nesting)

#t7 { @supports (display: flex) { ... } }

8. sintaxe desconhecida continua permissiva

@supports bananas-do-futuro(x)
